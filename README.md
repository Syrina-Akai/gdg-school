# GoMyCode × GDG School × ESI Workshop

Collaborative workshop hosted by GoMyCode, GDG School, and l'ESI focusing on an introduction to Artificial Intelligence and Machine Learning.

## Overview

This repository contains the learning materials, code notebooks, and presentation resources utilized during the hands-on workshop. 

### Workshop Agenda

The workshop tackled the following points:
- Introduction to AI
- What is Data & Essential Preprocessing
- Training Your First Machine Learning Model
- Introduction to Deep Learning & Use Cases
- Preparing Image Data for Deep Learning
- Building a Simple CNN for Image Classification
